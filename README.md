# QANYSH | Ғылым

**Әлем ғылымы қазақ тілінде.**

QANYSH — қазақ тіліндегі ғылыми-көпшілік портал.

## Ең бастысы: жаңа мақала қалай қосылады?

Енді `index.html` немесе JavaScript-ті өзгертудің қажеті жоқ.

### 1. `_posts` папкасына жаңа файл жасаңыз

Формат:

`YYYY-MM-DD-мақала-атауы.md`

Мысалы:

`2026-08-16-nasa-mars.md`

### 2. Файлдың басына мына блокты жазыңыз

```yaml
---
layout: post
title: "NASA Марсты зерттеудің жаңа нәтижелерін жариялады"
date: 2026-08-16 12:00:00 +0600
description: "Марсты зерттеу барысында ғалымдар жаңа маңызды деректер алды."
image: "/images/mars.jpg"
---
```

### 3. Одан кейін мақаланың мәтінін жазыңыз

Markdown қолданылады:

```markdown
Кіріспе абзац.

## Зерттеу қалай жүргізілді?

Негізгі мәтін.

## Бұл не үшін маңызды?

Негізгі мәтін.
```

### 4. Суретті `images` папкасына салыңыз

Мысалы:

`images/mars.jpg`

Содан кейін front matter ішінде:

`image: "/images/mars.jpg"`

### 5. GitHub-қа Commit жасаңыз

GitHub Pages Jekyll арқылы мақаланы өзі жинап, басты бетке шығарады.

## Қазіргі құрылым

- `_posts/` — **барлық жаңа мақалалар**
- `_layouts/post.html` — бір мақаланың сыртқы көрінісі
- `_layouts/home.html` — басты бет
- `_layouts/default.html` — ортақ шапка және footer
- `assets/style.css` — дизайн
- `images/` — мақалалардың суреттері және логотип
- `_config.yml` — сайт баптаулары

## Маңызды

Категориялар әзірге әдейі жоқ. Барлық мақалалар бір лентада шығады.

Кейін материалдар көбейген кезде `category` немесе `categories` арқылы:
Ғарыш, AI, Биология, Медицина, Физика, Технология және басқа бөлімдерді қосуға болады.
